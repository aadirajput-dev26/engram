# TASK: Complete End-to-End Evaluation of the 35-Page Government Report

You are testing our AI Document Intelligence / RAG system using the 35-page report that has already been ingested into the system.

Your job is NOT to modify the application or improve the answers.

Your job is to act as a rigorous QA/evaluation engineer and test the system comprehensively.

The final output MUST be a Markdown file containing every test question, the system response, retrieved sources/citations, and your evaluation observations.

Create:

TEST_RESULTS_35_PAGE_REPORT.md

Do not omit failed, empty, ambiguous, or incorrect results. Record them exactly.

==================================================
1. TESTING OBJECTIVE
==================================================

Evaluate whether the system can correctly:

1. Understand the contents of the 35-page report.
2. Retrieve relevant information from the correct pages.
3. Answer factual questions accurately.
4. Handle semantic/paraphrased questions.
5. Retrieve exact facts using keyword/hybrid retrieval.
6. Answer numerical questions correctly.
7. Answer questions involving tables.
8. Identify entities, departments, locations, dates, projects, quantities, amounts, etc.
9. Provide accurate page/source citations.
10. Ground answers in the uploaded document rather than hallucinating.
11. Handle multi-hop questions requiring information from multiple parts of the report.
12. Compare information from different sections/pages.
13. Identify contradictions or inconsistencies if present.
14. Handle questions whose answers do NOT exist in the report.
15. Avoid inventing information.
16. Handle OCR/scanned content correctly if applicable.
17. Retrieve information from headings, paragraphs, lists and tables.
18. Maintain traceability from answer → source → page.
19. Correctly route different types of questions through the system.
20. Produce useful answers for realistic government/administrative use cases.

==================================================
2. IMPORTANT RULE
==================================================

Do NOT manually answer the questions from your own knowledge.

For every question:

1. Send the question through the actual application/API/UI.
2. Record the exact response generated by the system.
3. Record every citation/source/page returned by the system.
4. Verify the answer against the actual 35-page report.
5. Determine whether the answer is correct.
6. Determine whether the cited page actually supports the answer.
7. Record any hallucination, missing evidence, wrong citation, wrong number, partial answer, or retrieval failure.

The report itself is the ground truth.

Do not silently correct the system response.
